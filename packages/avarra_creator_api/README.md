# avarra_creator_api

Pure-Dart Forge mutation boundary shared by human editor actions and future
automation. The Stage 10 foundation provides typed create/delete/transform and
rename commands, immutable validated world snapshots, undo/redo history,
canonical export, and a Game-entry validation gate.

It does not yet provide Stage 10A transactions, permissions, semantic diffs,
AI orchestration, or an MCP adapter.
