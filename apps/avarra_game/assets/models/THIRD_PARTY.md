# Original Relay Zero gothic kit

The files under `gothic/` are original AVARRA prototype assets assembled for
the Relay Zero action-RPG slice on 2026-08-14. The six glTF models use simple
project-authored geometry assembled from the CC0 cube mesh above. Their three
base-color materials were generated specifically for this project with
OpenAI's built-in image generation tool, then resized to 512 x 512 for runtime
use:

- `gothic/materials/basalt_flagstone.png`
- `gothic/materials/ember_bronze.png`
- `gothic/materials/ash_armor.png`

No third-party game characters, logos, or franchise assets are included. The
art direction is an original dark-gothic isometric action-RPG treatment.
